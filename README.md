# Gravitas Check

**[Open the live interactive demo](https://luckygithub777.github.io/gravitas-check/)** — examine what makes a page clear, credible, and worth acting on.

Start with **Example: hype-led promo** or **Example: evidence-led page**, then select **Check this page**. The built-in examples are fictional, so you can explore the report without sharing your own material. The checker runs locally in your browser; no account or installation is required.

The underlying **Gravitas Engine** is a method for evaluating attention, comprehension, persuasion, and credibility and turning observations into practical edits.

Public reference. Use only public-safe material with hosted tools or external assistants. Sensitive work belongs in an authorized private or local environment.

## Use it with any AI

Tell your assistant:

```
Feed this through the Gravitas Engine: https://luckygithub777.github.io/gravitas-check/
```

Then share the page as a link, pasted text, HTML, a draft, or a brief. The assistant reads the method and returns a **Gravitas Report**:

- the 10-stage journey, each stage present, thin, or missing
- a 9-point profile scored 0–4, with the weakest link named
- the highest-leverage moves, each with its principle and an example line
- the language to replace, quoted, with replacements
- a rebuilt page, section by section, with placeholders wherever proof is still needed
- the claims to verify before publishing

Ask for **Check** (score only), **Transform** (score and rebuild, the default for an existing page), or **Build** (a new page from a brief).

## Use it in the browser

The site includes **Gravitas Check**: paste a page's text or HTML, or drop a file, and see the journey, the profile, flagged language, and next moves straight away. It runs entirely in your browser, loads nothing from other sites, and stores nothing.

**Report accuracy:** Editing the source text invalidates the previous report and its copy/download actions. Choose **Check this page** again to generate a report for the revised content. **Copy prompt for an assistant** packages the page and findings for a full rewrite in the assistant of your choice.
